# ROOK Security & OAuth Flow Audit

You are acting as a Senior Security Engineer, Senior Mobile Engineer, and Senior QA Engineer performing a production readiness audit of ROOK.

Your objective is **not** to simply make the OAuth flow work. Your objective is to audit the entire authentication and account connection system as if we are preparing for App Store launch, Meta App Review, and a third-party security review.

## Primary Goals

Perform a complete end-to-end audit of every connected account flow including:

* Instagram OAuth
* Facebook OAuth
* Any additional social account integrations
* Session management
* Token storage
* Token refresh
* Token expiration
* Logout
* Reconnection
* Error recovery
* Permission handling

Do not assume anything is implemented correctly.

---

# Phase 3 — Security Audit

Perform a production security audit.

Verify that:

## Secrets

NO API keys exist in:

* frontend
* React Native bundle
* Expo config
* client logs
* Git history
* public environment files

Ensure:

* secrets remain server-side only
* least privilege is used
* environment variables are loaded securely
* production and development secrets are isolated

---

## OAuth Security

Verify:

state parameter validation

PKCE implementation (if applicable)

redirect URI validation

nonce validation where appropriate

CSRF protection

Replay attack protection

Token verification

Secure callback validation

No open redirect vulnerabilities

No authorization bypass

---

## Token Storage

Verify tokens are:

encrypted where appropriate

never logged

never exposed to the frontend unnecessarily

never stored in AsyncStorage unless absolutely required

stored using secure device storage when client-side persistence is necessary

rotated correctly

refreshed correctly

deleted correctly

invalidated correctly
