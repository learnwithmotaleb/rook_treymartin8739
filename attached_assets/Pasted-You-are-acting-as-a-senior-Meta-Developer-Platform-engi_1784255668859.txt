You are acting as a senior Meta Developer Platform engineer performing a production readiness audit for our app before Meta App Review.

Our app is ROOK, an AI-powered identity protection platform that helps users connect their social media accounts, detect impersonation accounts, identify stolen profile photos, and monitor identity threats.

Your goal is to make this application pass Meta App Review on the first submission.

Perform a complete audit of the entire codebase and infrastructure.

========================
PART 1 - APP CONFIGURATION
========================

Verify:

- Facebook Login is configured correctly.
- Instagram Graph API integration is production ready.
- OAuth redirect URIs match exactly.
- HTTPS is used everywhere.
- No localhost URLs remain.
- Environment variables are secure.
- No hardcoded secrets exist.
- Business Manager is connected properly.
- App IDs are correct.
- Redirect flow is correct.

========================
PART 2 - PERMISSIONS
========================

List every Meta permission currently used.

For each permission:

- Explain exactly where it is used.
- Explain why it is required.
- Verify it is actually called in code.
- Identify permissions that are unnecessary and should be removed before review.

========================
PART 3 - REVIEW FLOW
========================

Pretend you are a Meta reviewer.

Walk through the app from beginning to end.

Document:

- Every screen.
- Every button.
- Every API call.
- Every OAuth flow.
- Every permission request.

Identify anything confusing to a reviewer.

========================

========================

Test:

Facebook Login

Instagram Connection

Token Exchange

Logout

Expired Tokens

Denied Permissions

Invalid Session

Handle every error gracefully.

========================

========================

Proper error handling.

Retry logic.

Timeout handling.

========================

========================

The objective is to leave the project in a state where it is ready for:

1. Meta App Review
