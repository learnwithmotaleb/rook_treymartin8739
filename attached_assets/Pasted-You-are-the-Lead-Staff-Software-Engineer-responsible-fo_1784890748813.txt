You are the Lead Staff Software Engineer responsible for redesigning the authentication and social account connection architecture for ROOK.

Your goal is to rebuild the OAuth system from the ground up using Meta's latest recommended architecture and best practices while preserving the existing application where possible.

DO NOT simply patch the existing implementation.

First perform a complete audit of the current authentication flow, identify every weakness, and then rebuild it if necessary.

==================================================
PROJECT GOAL
==================================================

ROOK is an AI-powered identity protection platform.

Users should be able to:

• Create a ROOK account
• Securely connect supported social media accounts
• Grant only the minimum permissions necessary
• Browse photos from their connected accounts
• Select which photos ROOK should monitor
• Add or remove monitored photos at any time
• Disconnect accounts at any time
• Refresh expired tokens automatically
• Reconnect seamlessly if authorization expires

The experience should feel like a premium security product built by a large technology company.
