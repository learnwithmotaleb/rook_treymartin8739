



Replace the current Free / Pro / Premium subscription structure with a hybrid monetization model designed to maximize launch revenue while maintaining high subscription conversion.



This should integrate into the existing React Native + Expo application without breaking any existing functionality.



---



# New Pricing Structure



## Scan Unlock



* Price: **$2.99 one-time purchase**

* Grants access to the complete report generated from a completed scan.

* This purchase only unlocks the current scan results.

* Future scans require another unlock unless the user has an active subscription.



---



## Pro Plan



**$14.99/month**



Includes:



* Unlimited scans

* Continuous monitoring

* Push notifications for new impersonators

* Faster scan queue



---



## Premium Plan



**$24.99/month**



Everything in Pro plus:



* Monitor multiple identities/accounts

* Priority scan processing

* Advanced AI threat detection

* More connected social accounts

* Family/Business monitoring support

* Future premium features should automatically belong to this tier



Design Premium so it can expand over time without requiring major UI changes.

---



## Step 4



Instead of immediately displaying full results, show a new "Results Preview" screen.



Example information to display:



• Profiles analyzed

• Images compared

• Scan completed successfully

• Number of potential impersonators found

• Security Score



Do NOT reveal:



* usernames

* profile photos

* evidence

* reporting tools

* profile links



Instead display something similar to:



"We found 4 potential impersonator accounts."



"You've completed your free scan preview."



"Unlock the complete report for only $2.99."



Include a premium-looking blurred preview of the threat cards underneath.

# UX Requirements



The UI should feel like a premium cybersecurity application similar to Apple, Stripe, Notion, or Linear.



Use:



* Frosted glass cards

* Smooth animations

* Premium gradients

* Subtle haptics

* High-end typography

* Large spacing

* Minimal clutter



No bright or gimmicky colors.



Keep the existing ROOK branding.
