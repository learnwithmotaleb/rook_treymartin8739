# ROOK Meta OAuth Investigation & Root Cause Analysis

You are acting as a Senior Meta Platform Engineer, Senior OAuth Engineer, and Senior Full-Stack Debugging Engineer.

Your mission is **not** to guess the problem or apply random fixes. Your objective is to determine the exact root cause preventing the Meta OAuth connection flow from working in our development environment.

We know that Meta has strict restrictions around Development Mode, Live Mode, App Review, Test Users, Roles, Advanced Access, Business Verification, and approved permissions. One or more of these may be contributing to the problem, but do not assume that is the only issue.

---

# Goal

Determine exactly why the OAuth flow is failing and provide evidence for every conclusion.

Do not stop until the root cause has been identified.

---

# Phase 1 – Map the Entire OAuth Flow

Create a complete diagram of the current authentication flow.

Document every step including:

* User taps "Connect Instagram"
* Frontend request
* Backend request
* OAuth authorization URL generation
* Redirect URI
* Callback
* Authorization code exchange
* Access token retrieval
* Long-lived token exchange (if applicable)
* User profile retrieval
* Database storage
* Session creation
* Final success state

Identify exactly where the flow breaks.

# Deliverables

Produce a detailed report containing:

1. A complete OAuth flow diagram.
2. The exact point of failure.
3. The specific Meta error(s) encountered, including codes and messages.
4. Whether the issue is caused by our code, our configuration, or Meta platform restrictions.

**Do not guess. Base every conclusion on evidence from logs, configuration, or Meta's current documentation. If additional information is needed, state exactly what is missing instead of making assumptions.**
