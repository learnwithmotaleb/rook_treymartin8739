# ✅ CORRECT PRODUCT FLOW
---------------------------------------------------

1. User logs into Rook
2. User connects social accounts they own
3. Rook verifies ownership through OAuth/social login
4. The connected accounts become:
   THE VERIFIED CANONICAL IDENTITY
5. AI continuously analyzes those accounts
6. AI searches for impersonators using stolen identity signals

The verified connected accounts are the:
SOURCE OF TRUTH.

NOT username guessing.

---------------------------------------------------
# 🧬 IDENTITY SIGNAL EXTRACTION ENGINE
---------------------------------------------------

After user connects accounts, extract:

- usernames
- display names
- bios
- profile photos
- ALL public uploaded photos
- reels thumbnails
- public videos/images
- captions
- hashtags
- posting patterns
- follower metrics
- creator branding

This becomes:
the VERIFIED identity fingerprint.

---------------------------------------------------
# 🖼️ MOST IMPORTANT SYSTEM:
MEDIA REUSE DETECTION
---------------------------------------------------

The MOST important AI capability is:
detecting reused/stolen media.

The AI should monitor:
- profile photos
- ALL uploaded/public account photos
- reels thumbnails
- screenshots
- reposted content
- cropped/edited images
- creator assets

NOT just profile photos.

This is CRITICAL because impersonators often:
- use different profile pictures
- use old photos
- repost random content
- use screenshots from posts/reels
- use creator assets from older uploads

The AI should still detect these.

---------------------------------------------------
# 🧠 MEDIA ANALYSIS AI
---------------------------------------------------

Build AI systems that:

1. Extract media embeddings
2. Compare image similarity
3. Detect reposted content
4. Detect edited/cropped photos
5. Detect reused creator assets

Use:
- vector embeddings
- cosine similarity
- perceptual similarity scoring

The AI should detect:
- exact matches
- filtered matches
- resized images
- screenshots
- reposts
- cropped photos

---------------------------------------------------
# 🌐 IMPERSONATOR DISCOVERY ENGINE
---------------------------------------------------

The AI should continuously search for:
- suspicious accounts
- cloned creator pages
- fake business accounts
- catfish accounts
- scam giveaway pages

Using signals such as:
- reused media
- copied bios
- username similarity
- caption duplication
- creator branding similarity
- posting behavior

IMPORTANT:
The AI should still detect threats even if:
- usernames are completely different
- profile photos differ
- bios are rewritten

Because media reuse is the strongest signal.

---------------------------------------------------
# ⚖️ THREAT DETECTION PRIORITIES
---------------------------------------------------

Prioritize signals in this order:

1. Public media reuse
2. Reposted creator content
3. Profile image similarity
4. Bio similarity
5. Username similarity
6. Behavioral anomalies

MEDIA REUSE should have the HIGHEST weight.

Example:

Threat Score =
0.40 Public Media Similarity
+ 0.20 Creator Content Reuse
+ 0.15 Profile Image Similarity
+ 0.10 Bio Similarity
+ 0.10 Username Similarity
+ 0.05 Behavioral Signals
