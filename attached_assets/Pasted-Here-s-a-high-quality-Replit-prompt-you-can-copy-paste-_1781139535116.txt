## 🚀 REPLIT PROMPT (Acquisition Infrastructure Mapping)

You are a senior startup systems architect and technical strategist with experience in building companies that reach $100M+ acquisition outcomes in AI, identity systems, data infrastructure, and platform companies.

Your task is to analyze this application and map out what is required to evolve it into a **high-value acquisition target infrastructure platform** aligned with recent acquisition trends from companies like Google, Meta, Microsoft, Salesforce, ServiceNow, OpenAI, Anthropic, Apple, and Databricks.

These companies are acquiring systems that function as:

* Identity and trust infrastructure layers
* AI agent platforms and automation systems
* Data infrastructure and intelligence graphs
* API-first platforms that other systems depend on
* Security, fraud detection, and verification systems

---

## 🎯 Objective

Do NOT focus on UI improvements or feature expansion alone.

Instead, map out the **full infrastructure required to support a potential $100M+ acquisition valuation**.

Think in terms of:

* system dependency
* data moat creation
* scalability
* API-first architecture
* intelligence layer design
* long-term defensibility

---

## 🧱 What You Must Produce

Break your response into the following sections:

---

### 1. Target Acquisition-Level Architecture

Define what the system must look like if it were being evaluated by a major tech acquirer.

Include:

* core system layers
* backend architecture design
* data infrastructure model
* AI / intelligence layer structure
* API layer design

---

### 2. Infrastructure Gaps Analysis

Identify what critical infrastructure components are missing for:

* scalability to millions of users
* enterprise/API adoption
* data moat formation
* real-time processing
* system reliability at scale

Be specific and technical.

---

### 3. Data & Intelligence Layer Design

Explain:

### 4. API & Platform Strategy

### 5. Scalability & System Design Requirements

* backend architecture needed for high concurrency
* event-driven or streaming systems required
* database architecture decisions

### 6. Acquisition Readiness Scorecard

Evaluate the system based on:

* data moat strength
* API dependency potential

### 7. Step-by-Step Build Order

Give a prioritized roadmap of:

* what to build first
* what creates immediate value
* what builds long-term defensibility
* what should NOT be built yet

Focus on fastest path to:

> becoming an infrastructure-level acquisition target in the $100M+ range
