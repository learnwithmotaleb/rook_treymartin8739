# Rook Brand Naming

Use **Rook** as the only canonical product name in app-facing copy, notifications, documentation, and future implementation work.

**Why:** The product was previously referred to by a different working name, which caused inconsistent TestFlight startup and notification copy.

**How to apply:** Before shipping text changes, search case-insensitively for deprecated product-name variants and replace them with Rook, except where an internal historical filename must remain for task or asset identity.
